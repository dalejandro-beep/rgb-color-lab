Quick reference

Pixel: the smallest picture element in a digital image.
RGB: red, green, and blue light values (0–255).
HEX: a six-digit base-16 color code.

Black = (0,0,0) = #000000
White = (255,255,255) = #FFFFFF
Yellow = (255,255,0) = #FFFF00
